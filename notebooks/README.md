# Notebooks

This folder contains the main computational physics notebooks included in the project.

## Contents

| Notebook | Topic |
|---|---|
| `01_interpolation_lagrange_newton.ipynb` | Lagrange and Newton interpolation, NumPy and SciPy comparison |
| `02_numerical_integration_trapezoid_simpson_planck.ipynb` | Trapezoid rule, Simpson 1/3 rule, Planck's law and Stefan-Boltzmann check |
| `03_ode_solvers.ipynb` | Euler, modified Euler, predictor-corrector methods and SciPy `solve_ivp` |
| `04_stochastic_harmonic_oscillator.ipynb` | Stochastic initial conditions and percentile analysis for a harmonic oscillator |

Each notebook is designed to be readable, executable and suitable for a public technical portfolio.
